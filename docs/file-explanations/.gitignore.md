# .gitignore

## Purpose
Keeps build output, IDE files, secrets and dependencies out of git. Lines 1–482 are the standard `dotnet new gitignore` template plus the macOS and Windows sections. Lines 484–491 are project additions.

## Where it fits
Repo hygiene for both stacks. `frontend/.gitignore` adds Vite-specific patterns.

## Walkthrough
- **Line 7:** `.env` (dotenv files) comes from the template.
- **Lines 22–36:** `bin/`, `obj/`, `Debug/`, `Release/`, logs.
- **Line 294:** `node_modules/` (Node.js Tools section).
- **Lines 387–393:** VS Code files, except shared settings/tasks/launch/extensions.
- **Lines 484–488, "Tutoring Centre additions":** `node_modules/`, `dist/`, `.env`, `*.local.json`.
- **Lines 490–491:** `.claude/` (Claude Code local settings).

## Concepts used
- **Negation patterns** (`!`), e.g. `!Directory.Build.rsp` at line 92, re-include files that a broader pattern excluded.

## Data and control flow
Not applicable.

## Configuration and environment
Ensures `.env` (holding `POSTGRES_PASSWORD`) is never committed.

## Gotchas and issues
- `.env` and `node_modules/` appear twice (lines 7/487 and 294/485). This is harmless duplication.
- `*.local.json` (line 488) would also ignore any legitimately committed file with that suffix.
