# .gitignore

## Purpose

Lists files Git must not track: build output, IDE files, secrets (`.env`), dependency folders.

## Where It Fits

Root ignore file read by Git for the whole repo (the `frontend/` folder also has its own `.gitignore`).

## Walkthrough

About 450 lines, almost all the standard `dotnet new gitignore` template (header says 'Get latest from `dotnet new gitignore`'): Visual Studio/Rider/VS Code artefacts, `bin/`, `obj/`, test results, NuGet packages, coverage output. Project-specific parts:
- Line 4-5: `# dotenv files` / `.env` - keeps the local Postgres password out of git.
- Final block `# Tutoring Centre additions`: `node_modules/`, `dist/`, `.env` (repeated), `*.local.json`.
- Final block `# Claude Code`: `.claude/` - local Claude Code configuration/state is not committed.
Notable negation rules: `!Directory.Build.rsp`, `!.vscode/settings.json|tasks.json|launch.json|extensions.json`.
Edge case: `*.local.json` would also ignore a file such as `appsettings.local.json`; the repo has none.

## Concepts Used

### Secrets and configuration layering

#### What it means

Configuration comes from layered sources (JSON files, user-secrets, environment variables, command line) where later layers override earlier ones. Secrets must stay out of git: this repo keeps the connection string out of `appsettings.json`, reads it from user-secrets or an environment variable, and scans history with gitleaks.

(Full tutorial with execution traces: [PROJECT_OVERVIEW2.md#11-configuration--environment--deployment](../PROJECT_OVERVIEW2.md#11-configuration--environment--deployment).)

#### Where it appears in this file

The `.env` entries.

#### How it works here

Git never stages `.env`; `.env.example` (tracked) documents the keys.

#### Why it matters here

The only local secret in this project (Postgres password) cannot be committed accidentally.

## Data and Control Flow

No runtime data flows through this file; it is consumed by tooling or readers, not executed by the application.

## Configuration and Environment

Mentions `.env` (file) only.

## Gotchas and Issues

The file contains two sections that both ignore `.env` and `node_modules/` (duplicates are harmless).
