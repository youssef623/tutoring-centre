# .semantic-manifest.json

## Purpose
Machine-written bookkeeping for the **semantic-git** tool. It records which generated docs exist (`OVERVIEW.semantic.md`, `ARCHITECTURE.semantic.md`, `src/.semantic.md`, `tests/.semantic.md`), which paths each covers, and the commit they were last generated from.

## Where it fits
Tooling metadata for the generated `*.semantic.md` docs. The application never reads it.

- **Lines 5–33:** each doc's `covers` paths and `last_updated_commit`. All four are `42bdfc1`.

## Concepts used
- **Generated documentation with provenance:** the commit hash tells you how stale a doc is.
