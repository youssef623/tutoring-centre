# frontend/src/components/ui/badge-variants.ts

## Purpose

The `cva` variant table (class names) for the Badge component, kept in its own file.

## Where It Fits

frontend/src/components/ui. Imported by `badge.tsx`. Generated by the shadcn CLI, then project-owned. Prettier style differs (no semicolons).

## Walkthrough

`badgeVariants = cva(base, { variants: { variant: { default, secondary, destructive, outline, ghost, link } }, defaultVariants: { variant: "default" } })`. The base string sets an inline-flex 5-unit-high pill (`h-5 rounded-4xl text-xs font-medium`), focus ring classes and `aria-invalid` styles. `default` uses `bg-primary text-primary-foreground`, `secondary` uses the secondary tokens, `destructive` a tinted destructive background, `outline` a border, `ghost` hover styling, `link` an underlined link look.

## Concepts Used

### Tailwind, shadcn/ui and variants

#### What it means

Tailwind composes styles from small utility classes. shadcn/ui copies component source into your repo; `cva` (class-variance-authority) maps variant props like `variant="outline"` to class strings.
