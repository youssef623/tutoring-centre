# frontend/src/components/ui/alert.tsx

## Purpose
The shadcn/ui **Alert** component family: `Alert` (with `default` and `destructive` variants), `AlertTitle`, `AlertDescription`, and `AlertAction`. They are styled `<div>`s with `data-slot` attributes and `role="alert"` on the container.

## Where it fits
UI primitives, generated by the shadcn CLI (`components.json`). Used by `StatusCard.tsx` for the "Cannot reach the API" (destructive) and "database unavailable" (default plus amber classes) states.

## Walkthrough
- **Lines 5–19, `alertVariants = cva(base, { variants: { variant: { default, destructive } } })`:**
  - The base classes set up a grid.
  - When an `svg` icon is the first child, the layout switches to two columns.
  - When an `alert-action` slot exists, right padding is reserved.
- **Lines 21–34, `Alert`:** spreads `div` props, sets `data-slot="alert"` and `role="alert"`, and merges classes with `cn(alertVariants({variant}), className)`.
- **Lines 36–47, `AlertTitle`:** medium-weight font; moves to column 2 when there's an icon.
- **Lines 49–63, `AlertDescription`:** muted, balanced text, with spacing between paragraphs.
- **Lines 65–73, `AlertAction`:** `absolute top-2 right-2`.

## Concepts used
- **CVA (class-variance-authority):** typed variant-to-class mapping.
- **`cn`** from the `cn` package (shadcn's clsx + tailwind-merge replacement): conflicting Tailwind classes resolve, with the caller's class winning.
- **Tailwind `has-*` / `group-*` / `data-*` variants:** styling based on children and slots.
- **ARIA live region** via `role="alert"`.

## Data and control flow
Props → class string → DOM.

## Configuration and environment
None.

## Gotchas and issues
- **Physical CSS classes:** `text-left`, `pr-18` and `right-2` violate the README's logical-CSS/RTL rule, so the alert will look wrong in Arabic.
- **Implicit live region:** `role="alert"` makes screen readers announce the content immediately. Appropriate for errors; the amber warning reuses it.
- **Not Prettier-formatted:** no semicolons, which `.prettierrc` wants.
