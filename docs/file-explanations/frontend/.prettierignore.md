# frontend/.prettierignore

## Purpose

Tells Prettier which files not to format.

## Where It Fits

Frontend config read by `npm run format`/Prettier.

## Walkthrough

`dist`, `coverage`, `package-lock.json`, `src/routeTree.gen.ts`, `src/api/generated/**` - build output, coverage, the generated lockfile, the generated route tree (regenerated by the router plugin) and the Orval-generated API client (regenerated by `npm run generate:api`); formatting generated files would create churn and break the CI 'generated client is up to date' diff.

### Editor, line-ending and ignore configuration

#### What it means

Files such as `.editorconfig`, `.gitattributes` and `.gitignore` keep formatting, line endings and untracked files consistent across machines and operating systems.
