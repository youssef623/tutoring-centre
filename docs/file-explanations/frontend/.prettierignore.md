# frontend/.prettierignore

## Purpose
Tells Prettier not to format `dist`, `coverage`, `package-lock.json`, or the generated `src/routeTree.gen.ts`.

## Where it fits
Frontend formatting config, used by `npm run format`. Mirrors `eslint.config.js:10`'s ignores.

## Walkthrough
- **Lines 1–4:** the four ignore entries.

## Concepts used
- **Excluding generated files from formatters,** so the next regeneration doesn't produce a diff.

## Data and control flow
Not applicable.

## Configuration and environment
None.

## Gotchas and issues
- `src/components/ui/*` (shadcn output) isn't ignored, and those files don't conform to `.prettierrc`. `prettier --check` flags them.
