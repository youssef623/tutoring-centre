# frontend/.gitignore

## Purpose
The stock Vite `.gitignore`. It ignores logs, `node_modules`, `dist`, `dist-ssr`, `*.local` and editor files within `frontend/`.

## Where it fits
Frontend repo hygiene. It overlaps with the root `.gitignore`.

## Walkthrough
- **Lines 1–8:** log files.
- **Lines 10–13:** `node_modules`, `dist`, `dist-ssr`, `*.local` (e.g. `.env.local`).
- **Lines 15–24:** editor directories (VS Code except `extensions.json`, IDEA, `.DS_Store`, VS files).

## Concepts used
- **Nested .gitignore files:** patterns apply relative to this folder.

## Data and control flow
Not applicable.

## Configuration and environment
None.

## Gotchas and issues
- `*.sln` (line 23) would ignore a solution file placed in `frontend/`. Irrelevant in practice.
