# frontend/.gitignore

## Purpose

Ignore rules for the frontend folder (Vite template).

## Where It Fits

Frontend-local ignore file; complements the root `.gitignore`.

## Walkthrough

Ignores logs, `node_modules`, `dist`, `dist-ssr`, `*.local`, editor folders (`.vscode/*` except `extensions.json`, `.idea`), `.DS_Store`, `*.suo`, `*.ntvs*`, `*.njsproj`, `*.sln`, `*.sw?`. Template content plus a Playwright block (lines 15-19, comment 'Playwright (Day 18)'): `playwright-report`, `blob-report`, `test-results`, `/e2e/playwright/.cache` - reports, traces and browser caches produced by `npm run test:e2e`.
