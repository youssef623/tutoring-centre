# .gitattributes

## Purpose
One rule, `* text=auto eol=lf` (line 1). Git detects text files and checks them out with LF line endings on every OS, including Windows.

## Where it fits
Repo hygiene. It matches `.editorconfig`'s `end_of_line = lf`. The README shows PowerShell commands, so Windows contributors are expected.

## Walkthrough
- `text=auto`: Git decides which files are text and normalizes their line endings in the repository.
- `eol=lf`: text files are checked out with LF in the working tree.

## Concepts used
- **Line-ending normalization:** prevents CRLF/LF churn in diffs between Windows and Linux.
