# .env.example

## Purpose

Template for the git-ignored `.env` file that Docker Compose reads to configure the local PostgreSQL container.

## Where It Fits

Copied by the developer to `.env` (README step 2). Variables are consumed only by `compose.yaml`; the API gets the same credentials through its connection string (user-secrets), not through `.env`.

## Walkthrough

Lines: a comment, then `POSTGRES_DB=tutoring`, `POSTGRES_USER=tutoring_dev`, `POSTGRES_PASSWORD=` (blank).
- The comment says keep DB and USER unchanged because 'the API's connection string and the Compose healthcheck use these names' (README's `dotnet user-secrets` command uses `Database=tutoring;Username=tutoring_dev`).
- The blank password is deliberate; `compose.yaml` uses `${POSTGRES_PASSWORD:?...}` so Compose refuses to start until it is set.

## Concepts Used

### Docker and Docker Compose

#### What it means

A container runs a program in an isolated filesystem from an *image*. Compose describes one or more containers (ports, environment, volumes, healthchecks) in YAML so a dev environment starts with one command. A *named volume* persists data beyond the container's life.

(Full tutorial with execution traces: [PROJECT_OVERVIEW.md#11-configuration--environment--deployment](../PROJECT_OVERVIEW.md#11-configuration--environment--deployment).)

#### Where it appears in this file

The three variables.

#### How it works here

Compose substitutes `${POSTGRES_DB}`, `${POSTGRES_USER}`, `${POSTGRES_PASSWORD}` from `.env` into the service definition.

#### Why it matters here

Defines the dev database identity in one place.

## Data and Control Flow

No runtime data flows through this file; it is consumed by tooling or readers, not executed by the application.

## Configuration and Environment

Variables defined here: `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` (secret, blank in the template). Used in `compose.yaml` lines 4-6 and the healthcheck.

## Gotchas and Issues

The password must be repeated by hand in the user-secrets connection string; README warns it must contain no `;` or spaces (they would break the connection-string syntax).
