# Tutoring Centre — Overview

A .NET backend for a tutoring centre, built as a portfolio project and structured around Clean Architecture. The same business logic is meant to eventually serve a staff web app, a WhatsApp assistant, and background jobs, so the code is organized to keep business rules independent of any specific delivery mechanism (HTTP, chat, cron). See `docs/adr/0001-clean-architecture.md` for the full reasoning behind this structure.

Right now the project is at an early, infrastructure-focused stage: the four-project skeleton exists, health checks and a local PostgreSQL setup are wired up, and architecture rules are enforced by automated tests. No business features (students, bookings, payments, etc.) exist yet.

## Who this is for

Primarily a single developer demonstrating Clean Architecture, dependency inversion, and "architecture as code" (fitness functions) for .NET job interviews. Someone opening this repo cold should be able to see, from the tests alone, what the architecture rules are — not just read them in a document.

## Getting started

1. **Prerequisites**: .NET SDK pinned by `global.json` (10.0.x), Docker (for local Postgres).
2. **Start the database**: `docker compose up -d` — starts a `postgres:17` container. Needs a `.env` file (copy `.env.example`, fill in `POSTGRES_PASSWORD`).
3. **Set the connection string**: `dotnet user-secrets set "ConnectionStrings:Postgres" "Host=localhost;Port=5432;Database=tutoring;Username=tutoring_dev;Password=<same as .env>" --project src/TutoringCentre.Api`
4. **Build**: `dotnet build` from the repo root (the `.slnx` solution lives there).
5. **Run the API**: `dotnet run --project src/TutoringCentre.Api` — then `GET /health` and `GET /health/ready` (see below).
6. **Run tests**: `dotnet test` from the repo root.
